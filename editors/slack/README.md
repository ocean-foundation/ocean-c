# Ocean Lang for Slack

Paste one of the theme strings below into Slack under **Preferences → Appearance → Custom theme → Import** (or send it in a message to yourself and click **Switch sidebar theme**).

## Ocean Dark

**Modern Slack (4 colors — System Navigation, Selected Items, Presence, Notifications):**
```text
#081120,#22395c,#83a271,#d8736b
```

**Classic Slack (8 colors):**
```text
#081120,#0d182b,#22395c,#e8eff9,#182b46,#c2ccd6,#83a271,#d8736b
```
